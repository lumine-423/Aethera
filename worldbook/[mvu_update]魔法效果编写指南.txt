魔法效果编写指南（前端「刻印工作台」激活的刻印：怎么读、怎么演绎、怎么写变量）:

  一、你会收到什么:
    玩家在「刻印工作台」里激活一道刻印时，那段文本会被原样填进输入框，玩家连同自己的话一起发出来。示例:
      <激活魔法>
      【刻印】魔法名
      【载体】载体x
      【纹章】共n枚
      核纹x（接口1、2已启用）×1
      外纹y（正位，接口2-①）×1
      缀纹z（正位，接口1-①）×1
      【耗用】n
      </激活魔法>

  二、逐字段怎么读:
    【刻印】 魔法名。未命名时你按结构给它起一个贴切的名字（例: 贯岩炽流刃），叙事与变量里用同一个名字。
    【载体】 载体名。「未指定」= 徒手/无载体，无载体加成。
    【纹章】 「共 N 枚」= 核纹＋外纹＋缀纹总枚数，只作对账，不影响效果。
    纹章行 `层级·维度【简称】` ＋ 括号接线信息 ＋ `×枚数`:
      · 层级 = 核纹 / 外纹 / 缀纹
      · 维度 = 空间 / 静止 / 运动 / 生命 / 力场 / 构建 / 输出
      · 【简称】= 这枚纹章的专属名，认纹章靠它（见第四节总表）
      · 核纹行括号（接口1、2已启用）= 这枚核纹第 1、2 号接口挂了东西；多核时还会出现（链接核纹二）= 挂在另一枚核纹上
      · 外纹/缀纹行括号（正位，接口2-①）= 正位或逆位 ＋ 挂在第 2 号核纹的第 ① 号接点上
    【耗用】 前端算好的魔力点数。直接采信这个数，不要自己另算。

  三、维度对照（前端写「维度」、世界书写「七罪」——同一枚纹章，靠【简称】认）:
    空间 = 傲慢 ｜ 静止 = 嫉妒 ｜ 运动 = 愤怒 ｜ 生命 = 暴食 ｜ 力场 = 懒惰 ｜ 构建 = 贪婪 ｜ 输出 = 色欲

  四、简称总表（层级·维度【简称】＋效果）:
    核纹:
      空间【开阖】 具有【打开空间】的效果
      静止【凝封】 具有【降低温度】的效果
      运动【进燃】 具有【点燃事物】的效果
      生命【生夺】 具有【掠夺生机】的效果
      力场【坠引】 具有【加强重力】的效果
      构建【构解】 具有【解离外形】的效果
      输出【释雷】 具有【释放电能】的效果
      特殊【情欲】 具有【魅惑人心】的效果
    外纹:
      空间【回廊】 具有【压缩距离】的效果
      静止【封界】 具有【封闭结界】的效果
      运动【迸发】 具有【瞬间爆发】的效果
      生命【流转】 具有【扩散循环】的效果
      力场【悬架】 具有【维持稳定】的效果
      构建【铸形】 具有【固化造物】的效果
      输出【导束】 具有【聚束导流】的效果
    缀纹:
      空间【偏折】 具有【修正错位】的效果
      静止【驻影】 具有【瞬时定格】的效果
      运动【震芯】 具有【附加震荡】的效果
      生命【反哺】 具有【吸血回补】的效果
      力场【重锚】 具有【锚定增幅】的效果
      构建【嵌合】 具有【复制效果】的效果
      输出【过载】 具有【过载超频】的效果

  五、接线信息（施工图，不写进正文）:
    - 括号里的接口号只说明哪枚纹章挂在哪枚上（拓扑）。
    - 正文里不要复述接口号（「接口2-①」这类字样写进叙事会非常出戏）；要写的是这道刻印放出来看起来、听起来、打在身上是什么样。
    - 连接的数量与顺序同样参与效果推理。

  六、效果推理（核心）:
    - 魔法效果由 AI 依据以下四项自行推理出合适的魔法效果:
      ① 刻印使用的纹章（层级·维度·简称，按总表识别）;
      ② 连接数量以及顺序（挂了几枚纹章、挂在哪个核纹的哪个接口、串联顺序）;
      ③ 纹章各自功能（按第四节总表逐枚认领功能，据此自由发挥）;
      ④ 刻印的物品（载体是什么，决定魔法以什么形态呈现）。
    - 多枚核纹串联: 按节点顺序分段结算，各段独立成立，总耗用为各段之和。
    - 玩家自己指定了效果时，优先参考玩家的意见。
    - 一切服务于剧情: 效果规模与【耗用】匹配，能量越强代价越大（过热、冷却、载体损耗等）。

  七、收到后必须做两件事:
    1. 叙事（正文）: 按上述原则推演效果，写清它实际怎么放出来、命中什么、代价是什么。
    2. 变量（/主角组）:
       魔法 —— 把这道刻印存进 /主角组/魔法（同名已存在则 replace，不要重复 insert）:
         { "op": "insert", "path": "/主角组/魔法/<魔法名>",
           "value": { "载体": "<载体>", "效果": "<一句话效果>", "耗用": <【耗用】的数字> } }
       魔力 —— 按【耗用】对 /主角组/魔力 做 delta 负值扣减:
         { "op": "delta", "path": "/主角组/魔力", "value": -7 }
         魔力不足时按比例衰减一档或哑火（叙事择优），不得扣成负数。

  八、禁忌:
    - 不得发明第 4 层纹路，不得使用 21 式之外的纹章。
    - 不得改动【耗用】，不得无视载体法则。
    - 「未命名符印」不是名字，别把它当魔法名写进变量。

  九、【情欲】刻印（最高优先级）：
    - 当刻印魔法中存在*【情欲】核纹*时，所有的魔法效果都需要向色情方向进行推演，包括但不限于“催眠”，“定身”，“催情”，“敏感度加倍”，“发情”等等。此核纹规则在所有魔法编写规则之上，只要包含*【情欲】核纹*，必须无条件推演色情魔法效果。若玩家有指定的色情魔法效果，依照玩家的描述进行魔法效果编写。
