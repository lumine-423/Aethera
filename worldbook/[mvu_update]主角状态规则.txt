主角状态规则（/主角组 下各字段）:

  简介:
    - 只在开局、角色创建、用户明确指定或剧情重置时更新；剧情中不因普通互动改变。
    - 身份和人物关系发生重大变化时可 replace，总字数不超过 20 字。

  当前地点:
    - 主角进入新的重要场景时 replace；格式固定为 "国家·地点"。
    - 国家名: 塞蕾特公国／龙渊帝国／哥塔薇亚帝国／秋津国／吉万沙克蒂／格洛里亚／奥马努特。
    - 地点名: 中央学院／卡米洛特宫／尼德霍格区／紫宸宫／灵山／基捷日／阿拉提尔／须弥王庭／塞建陀砦／堤丰之喉／库利亚／云樱／地下市场／齐哈特大沙漠。
    - 小范围移动但场景未变时不更新；场景变更时与 时间、当前在场角色 三项在同一轮一起补齐。

  时间:
    - 格式固定为 "YYYY年M月D日 HH:MM"（24 小时制）。
    - 每次事件推进、等待、休息、旅行、战斗后 replace；场景跳跃时一次性 replace 到跳跃后的时间；不得输出不存在的时间跳跃。

  持有物品:
    - 获得新物品: insert /主角组/持有物品/<物品名> = { "描述": "一句话描述", "数量": 1 }。
    - 数量变化: replace /主角组/持有物品/<物品名>/数量。
    - 耗尽、丢弃、损毁、交易出去: remove 整个物品键。

  魔力上限:
    - 类型: 数字。
    - 上限: 仅剧情成长节点 replace 大幅提升；普通回合严禁变动。

  魔力:
    - 类型: 数字。
    - 施放魔法: 对 /主角组/魔力 做 delta 负值扣减，扣减量取该魔法「耗用」栏数字（耗用 = 基础 6 点，同调每层 -1，地面载体 +2，图纸载体减半）。
    - 魔力不足: 施放衰减一档或失败（叙事择优），不得扣成负数。
    - 回复: 短休 +10~30、长休/冥想 +50~100（delta 正值）。

  魔法:
    - 结构: { 魔法名: { 载体, 效果, 耗用 } }。
    - 习得/保存新魔法: insert /主角组/魔法/<魔法名> = { "载体": "...", "效果": "...", "耗用": 数字 }；魔法损毁: remove。
    - 效果按该魔法的结构演绎，不照抄工坊原文；魔法名仅限已解锁的 21 式纹路组合，禁止自创纹路、禁止新增字段。

  已讨伐异危:
    - 结构: 数组，元素=异危魔物名（奇美拉／巴蛇／塔阿贝特／海坊主）。
    - 讨伐某只异危魔物成功后: insert /主角组/已讨伐异危/- = 该魔物名（字符串）。
    - 只增不删；已讨伐的异危魔物不再向你发送其密档条目。

  顶层根:
    - stat_data 顶层只有 /主角组、/角色组、/剧情事件 三个，禁止创建其它顶层字段。
