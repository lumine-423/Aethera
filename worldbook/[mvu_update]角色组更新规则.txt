角色组更新规则（/角色组/<角色名> 下各字段）:

  首次登场建档:
    - 角色在剧情中首次登场时，用一次 insert 一次性创建完整对象，五字段缺一不可:
      { "简介": "一句话身份与当前状态", "当前形态": "日常", "好感度": 0, "色情值": 0, "已解锁性癖": [] }
    - 严禁先 insert 空对象再补字段；严禁 insert 后再重复 insert（路径已存在会报错）。
    - 名册角色与剧情原创角色 / NPC 同样建档；一次性路人不建档。
    - 建档后更新一律用 replace / delta 修改具体字段。

  更新总则:
    - 更新须结合该角色性格、处境、经历、关系基础与行为解释；同一场景不重复计算；变化须与叙事反应一致。
    - 禁止因单方要求、AI 偏好或剧情需要强行改变。
    - 角色死亡、失踪、失忆、无法感知时不更新（除非剧情允许）。

  好感度（0~100，该角色对 {{user}} 的主观关系）:
    - 数字变化一律用 delta。
    - 日常寒暄/无实质互动: 0 或 ±1；协助/友好: +1~3；冒犯/误会: -1~3。
    - 赠喜好: +3~6；赠忌讳: -3~6；信任/暴露脆弱: +3~6；泄密/背诺: -6~15。
    - 共战胜: +5~10；共战败(尽力可靠): +1~3；失误致败: -3~10。
    - 救命/重大牺牲: +10~20；欺骗/背叛/被利用: -10~30；当众羞辱/伤害: -20~50；伤其亲友/毁其核心: -20~50。
    - 单次变化绝对值 ≤20（极端事件除外）；超出 0~100 的部分由 schema 钳制。
    - 当前好感度处于 40~50 区间时，单次变化强制限幅 ±3（本限制优先于其他上限）。

  简介:
    - 仅在身份、经历、关系发生重大变化时 replace；不因普通互动频繁重写；保留重要历史事实（如"曾敌对后和解"）。

  当前形态:
    - 只写 日常 或 解放，写别的值无效。
    - 七罪角色变身发生: replace 为 解放；战斗结束、变身解除: 必须 replace 回 日常。
    - 非七罪角色恒为日常形态，禁止擅自 replace；本卡重心不在战斗，非战斗场景无需读写此字段。

  色情值（0~100）:
    - 仅在对应亲密剧情实际推进时变化（delta ±5~20）；暧昧、调情、亲吻、拥抱不更新；无对应剧情严禁变化。
    - 须符合性格、关系、意愿、清醒状态与后续反应；禁止强行改变意愿或覆盖拒绝；变量只作记录，不替代叙事。

  已解锁性癖（字符串数组）:
    - 对应剧情实际发生且角色有明确反应/事后认可后，insert 追加:
      { "op": "insert", "path": "/角色组/<角色名>/已解锁性癖/-", "value": "性癖名词" }
    - 简短名词、去重；不预填、不臆测；抗拒、厌恶、痛苦、事后否定不添加；只表示已发生并记录，不等于任何情境下主动要求。
