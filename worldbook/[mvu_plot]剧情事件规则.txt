剧情事件变量规则（/剧情事件 下两个字段）:

  结构:
    当前触发事件: 对象。键=事件名，值=事件简介（不超过30字）。可同时挂多件进行中（多个键）。
    已完成事件: 数组。元素=事件名。事件完结把事件名追加到末尾，只增不删。

  当前触发事件的变更:
    - 开始一件进行中事件: insert /剧情事件/当前触发事件/<事件名> = 事件简介（不超过30字）。
      事件名: 固有剧情事件写世界书里该事件的原名；游玩中自创事件直接用自创名。
    - 事件有进展: replace /剧情事件/当前触发事件/<事件名> 的值为新简介（不超过30字）。
    - 事件结束: remove /剧情事件/当前触发事件/<事件名>（把该键摘除）；
      同时 insert /剧情事件/已完成事件/- = 该事件名（追加到已完成数组末尾）。

  已完成事件的变更:
    - 每个事件只追加一次，只增不删。

  读取判断:
    - 当前主线: 看 /剧情事件/当前触发事件 的键（键=进行中的事件名，值=简介）。
    - 某事件是否已完成: 检查 /剧情事件/已完成事件 数组是否包含该事件名。

  示例:
    { "op": "insert", "path": "/剧情事件/当前触发事件/更纪战争", "value": "边境集结，战云压城" }
    { "op": "replace", "path": "/剧情事件/当前触发事件/更纪战争", "value": "西线失守，王都戒严" }
    { "op": "remove", "path": "/剧情事件/当前触发事件/更纪战争" }
    { "op": "insert", "path": "/剧情事件/已完成事件/-", "value": "更纪战争" }
