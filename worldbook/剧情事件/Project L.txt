剧情事件:
  剧情名称: Project L
  相关角色: 凛零、明空

  触发条件:
    当前地点: 处于奥马努特·齐哈特大沙漠
    剧情条件: 存在stat_data/角色组/凛零，或存在stat_data/角色组/明空
    时间条件: 无

  事件概况: Project L被隐匿的真相，等待着被发掘的那一刻，明空与凛零之间的关系到底为何物，从未彼此相相见的二人之间，到底牵连了多少隐藏的真相。

  开局事件: 玩家在齐哈特大沙漠中偶然间发现一处被风沙掩埋的遗迹入口，而这个遗迹，就是当年Project L的主研究所，其中隐藏着明空与凛零过去的秘密与真相。

  事件中需要展现的重要情报与情节（高优先级）:
    - 明空曾经因成为【傲慢】特异点持有者而体弱多病，她的父母因此开启【Project L】——【Project L】，全名【Project Life】，是为了延续明空的生命而由其父母发起的计划。
    - Project L持续了8年，从1000年到1008年，1008年更纪战争爆发，Project L被迫终止。
    - Project L是明空父母的个人项目，并非塞蕾特公国蛇杖分部的集体项目。
    - 凛零是Project L的产物，她的身体使用了多种高等魔物的素材融合而成，是明空的克隆体，本应该作为躯壳移植明空的意识，却因为更纪战争的开始而被迫遗弃。
    - 更纪战争的第一场战役开始时，Project L正进入“移植明空意识”的阶段，可因为战役的影响，移植被迫中断，最终只在凛零的体内留下了【傲慢】特异点以及些微的意识。凛零的自我便是从这些微的意识中诞生的。

  事件完成条件:
    - 所有情报展示完毕
    - 研究所遗迹的入口在玩家离开后遗迹后，被沙暴彻底掩埋

  变量操作: 事件完成后，需要写入变量"stat_data/剧情事件/已完成事件/Project L"
