规格：**768×768 透明 PNG（RGBA，四角 alpha=0）**，普通魔物展示画布比异危魔物小，此尺寸够用。

## 风格口径

与异危魔物同一套：**神秘学半写实**——材质有真实磨损与纹理，光影过渡细腻但保留绘画笔触，不是照片级也不是赛璐璐平涂。

普通魔物与异危的差别（用户拍板）：

- **不带符文、法阵、发光刻纹**，特效只保留自然元素（沙尘、热流、蜃气）
- 不铺场景，只有本体和极少量接地投影
- 画面内不含任何文字、水印、角标、AI 生成标识

## 切分脚本

- `crop_batch.py`：按透明间隙 + 投影分带切分，按 row-major 命名归档（适用于四格分离良好的图版）
- `fix_split.py`：图版内两格轻微相触时，先做形态学腐蚀断开，再按断开后的中点边界取块
- `fix_frag.py`：剔除切块边缘粘上的邻格残肢（判据：碎片外扩 26px 仍挨不到主体才删）

## 已知情况

- 图版 C、D 左右两格各有尾尖相触（约 14–16px 桥接），已用腐蚀断开，主体验证无切损。
- 沙盗秃鹫、流沙鳄、沙下潜行者、沙鬼、沙鸣琴蜘蛛切块时曾带进邻格残肢，已清除。
- 流沙鳄、沙下潜行者、沙鬼保留极淡的接地投影，用于避免腾空感；如需纯透明可再抹。
