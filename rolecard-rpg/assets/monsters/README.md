生成日期：2026-11-15
本目录覆盖 **8 尊异危魔物（1024×1536）+ 八地区 106 种常规魔物（768×768）**，全部透明 PNG。

风格（第三版口径，用户拍板）：**神秘学半写实**——材质有真实的磨损、锈斑、断口与热辐射，光影层次细腻但保留绘画笔触，既不照片级也不赛璐璐平涂；**允许特效缠绕本体并溢出轮廓**（符文环、毒雾、灰烬光尘、焰丝、孢子），但背景始终全透明、不出现任何场景。

镜头：**一尊一机位，不固定单一视角**，靠机位落差与体量差制造异危魔物的压迫感与危险感。

生成模型：**Seedream 5.0 flash**（透明底原生输出，8 尊实测透明通道全部通过）。

画面内**不含任何文字、水印、角标、AI 生成标识**。

### 生产方式：4 只一张图版 + 自动切分

106 种只用 **27 次生图**（齐哈特 6 + 其余七区 21），平均每次出 3.9 个可用单体。图版按 2×2 排列，四只轮廓之间留透明通道，切分时按透明间隙自动定位，不需要手工抠图。

## 生成与切分脚本

全部在 `F:\sigil-circuit\_out\monster-codex\`：

| 脚本 | 用途 |
|---|---|
| `build_monsters.py` | 8 尊异危：下载 + 统一 1024×1536 画布 + alpha/角标校验 |
| `crop_batch.py` | 四格分离良好的图版，按透明间隙 + 投影分带直接切 |
| `fix_split.py` | 相邻两格轻微相触时，先形态学腐蚀断开，再按断开后的中点边界切 |
| `fix_frag.py` | 剔除切块边缘粘上的邻格残肢（判据：外扩 26px 仍挨不到主体才删） |
| `build_all.py` | 七区总装：alpha 阈值 + 腐蚀次数双重自适应，一次跑完 21 张图版 |
| `gen_index.py` | 从 worldbook 条目自动生成各地区 README 并核对完成度 |

## 已知情况

- 图版中若相邻两只的尾尖或翅尖相触（模型未完全留白），靠 `build_all.py` 的腐蚀自适应分离，实测最多需腐蚀 20 次（龙鳞蟒那格），主体均无切损。
- 极少数图版内残留 1～2 像素级的邻格碎屑，不影响使用；需要完全干净时跑 `fix_frag.py`。
- 部分魔物保留了极淡的接地投影（战马、鳄类、龟类等），用于避免腾空感。
- 已知与设定有偏差的个体：沙暴巨蝎（设定双尾，出图仅一尾）、双尾林狼（分叉尾不明显）、夜市窃灵猫（三尾未明确画出）。如需修正单独重出即可。
