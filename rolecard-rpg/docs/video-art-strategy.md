## 视频→透明PNG→图集

已核实本机C:/ffmpeg/bin/ffmpeg.exe与ffprobe.exe，版本8.0.1。不重复下载。工具源码tools/video_assets.py复制至独立目录工具，运行doctor/inspect/extract/pack。输出必须新目录，源不覆盖；失败保留现场。PNG保留alpha；角色画布/锚点固定，禁止每帧独立裁切/自动抻拉。24/30fps是采样参数，不能补足视频缺失的运动信息；工具拒绝输出fps高于源平均fps。可变帧率需明确统一采样后再打包。

现成方案核查：
- [FFmpeg filters](https://ffmpeg.org/ffmpeg-filters.html)：fps采样、RGBA转换、colorkey/chromakey；当前封装使用RGBA colorkey。平底优先，底色不能撞角色发色/衣服。叶绿色发不适合绿底，可选原画无同色的品红或其他纯色，仍以样片检查为准。
- [rembg官方项目](https://github.com/danielgatis/rembg)：已有本地图片/批处理与FFmpeg管线，可做复杂背景候选。当前未安装，Python3.14与模型/权重适配未验证；不自动下载权重，不用云API。逐帧抠图可能边缘跳变，需视频样本验收。
- [RobustVideoMatting官方项目](https://github.com/PeterL1n/RobustVideoMatting)：提供视频抠像与多种运行后端，列为复杂背景候选；主要演示真人，不能推断像素动漫适配已通过，当前未安装/未跑。

工具实际支持保留已有透明、纯色抠除/抽帧、固定画布图集。复杂背景模型工具已找到但未伪称集成。推荐先让视频模型固定镜头/原地动作/无背景阴影/纯色不撞色底/无镜头摇晃，将镜头和技能特效留游戏内独立做；否则模型镜头位移会混进角色图，抽帧不能自动分离。

命令（在外部目录运行）：
```
python 工具/video_assets.py doctor
python 工具/video_assets.py inspect 输入视频/角色动作.mp4
python 工具/video_assets.py extract 输入视频/角色动作.mp4 输出序列/新批次 --fps 24 --mode chroma --color FF00FF
python 工具/video_assets.py pack 输出序列/新批次 输出序列/新图集 --fps 24 --columns 8 --actor rin --form base --action attack --anchor-x 128 --anchor-y 352
```

最后一条示例根点要按实际画布填写。图集超过4096时工具拒绝，先缩小整条序列的固定画布或切分动作；不得悄悄降低帧率/丢帧过关。验收包括实时间隔、透明底、黑/白/复杂背景边缘、循环/收招、人设与体积，不能只看帧数。
