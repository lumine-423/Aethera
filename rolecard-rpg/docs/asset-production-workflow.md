## 可单独执行的本地命令

```powershell
# 读取已有任务，零生图调用
python tools/art_pipeline.py status --job rin-motion-05
# 只读一个角色（稳定ID如rin、castor、jian），不重读整书
python tools/art_pipeline.py profile --job rin-motion-05 --actor castor
# 打印原调用提示词，不发起网络请求
python tools/art_pipeline.py prompt --job rin-motion-05
# 固定输入没变时，单独重建边界分析
python tools/art_pipeline.py analyze --job rin-motion-05
# 单独调用Aseprite导出，并做结构检查；不会发起生图
python tools/art_pipeline.py build --job rin-motion-05
# 已导出且未变时只检查，避免重复构建
python tools/art_pipeline.py check --job rin-motion-05
```

`build`内部调用`tools/build_motion_v2.ps1`，再由`tools/build_rin_motion_v2.lua`处理；PowerShell等待Aseprite真正退出并检查退出码。自动目标强制以`.generated.aseprite`结尾，防误覆盖人工源。开始人工精修时复制/另存为新源、记录新任务/导出入口，不能把精修放回可自动覆盖的文件。

## 新任务最少需要什么

先复制任务合同为**新ID**并只改实际差异：角色/形态/动作、来源、提示词文件、候选输出指纹、制作/检查入口和验收目标。M0动作卡至少包含：进入/结束状态、身体与视线意图、起势/发力/随动/收招、脚接触和是否有意挪步、附属物延迟、角色性格、不得出现的表现、当前技能效果、未定项。

生图提示词采用“身份/服装/比例不变＋本动作的关键姿势与人设意图＋输出约束＋明确避免项”。自然、优雅、帅气只是方向，必须翻译成重心、轨迹、节奏、手势和收招。**不要求模型仅凭“帅气”二字生成整套动作**。独立生成图无法保持体积/轨迹时，转为少量关键姿势＋Aseprite可控补帧；不反复整张重抽。

本地检查不变就复用结果；源码/图集改变才跑对应检查，协议没改就不重复全量协议测试。失败保留输入和证据，用一段有边界的修正处理；同类生成失败重复出现时停止盲抽，把问题交到具体像素关键帧。每轮交接必须注明是否真的需要新的生图能力，否则默认从本地产物续作。
