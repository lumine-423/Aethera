# 游戏专属角色设计与世界书更新规则

日期2026-10-27。用户已直接批准本文件中的游戏改编。它补充实际世界书资料；世界书快照只记录读取当时的事实，不能用旧快照否决用户后续设计。原活卡/世界书本轮没有修改。

## 依据顺序和资料更新

1. 用户最新直接说明优先，其次是已经确认的项目决定，再是相应版本世界书，最后才是执行者的候选设计。
2. 来源审计JSON与快照保持原样，保留“当时写了什么”；当前可制作/可启用规则写在本文件、decisions和动作清单中。旧资料中的飞星锁定、明空非战斗不再作为游戏制作禁令。
3. 世界书后续改变时，比对相关角色条目的ID、正文指纹与增删变化，记录影响到哪个动作/技能映射。只更新受影响的设计与资产，不因此全工程推倒或丢弃已接受成果。
4. 来源指纹变化意味着需要复核资料，不等于用户已批准的游戏改编被自动撤销。发现实质设计冲突时保留双方依据，再处理真正影响制作的部分；没有冲突的工作继续。
5. 当前游戏运行夹具technical-fixture-01仍只有测试规则。以下是已经获准的制作方向，正式数值、技能执行与演出尚未完成。

## 飞星：已允许制作的大招

- 用户定义：**超加速，突破空间限制**。可制作、可用于游戏；不再要求等待旧世界书的“未解锁”状态先改变。
- 根据现有鸟羽形态资料，先绑定凛零released形态的ultimate槽开展设计；这不额外增加第九种形态动作，也不把解放过渡和大招合并。
- 动作分镜候选：清楚的加速准备→身体与浮游翼片协同发力→短促高加速与空间突破表现→明确落点/作用点→减速收束回本形态待机。具体攻击轨迹、目标数、段数仍由技能设计确定，不以此擅定“必定多段/全体”。
- 画面要能读出超加速的过程与方向，保留关键剪影和起止空间关系。残影、像素拉伸帧和空间裂线可作为候选，但不能用全屏白闪替代角色动作，也不改变统一像素显示标准。
- 命中/效果由规则一次提交，暂停/跳过/重载只改变表现进度；不能每出现一道残影就再次扣血。

## 降神：游戏内的高消耗、高伤害、高代价大招

- 用户已明确允许游戏与剧情采用不同规则。梅林released形态的ultimate槽可设计为降神，不沿用剧情“一次性永久失去”的禁用方式。
- 保留其黄金巨像/巨大压制感的身份，采用角色指挥、巨像构筑、释放与收束的完整像素演出；不能只在背景贴一张巨像图。
- 数值设计必须同时落实三个部分：**高消耗**（可读资源成本）、**高伤害**（与同档技能比较的显著收益）、**高代价**（施放后的真实战术损失）。具体资源系统尚未冻结，不凭空增加一套长期养成资源。
- 代价候选可从施放后短期虚弱/行动恢复变慢/局内生命或其他已采用资源代价中选适量组合，通过纸面战斗和测试对局决定。候选不是全部必装，也不能用只有动画变暗的假代价充数。
- 按钮在确认前明确显示消耗与代价；资源不足时不扣任何成本并说明原因；一次确认只提交一次。跳过、重载和重复回调不能免除或重复代价。
- 改编的成本、伤害和副作用局限于游戏状态。回卡结果可报告已用技能与局内结果，但不能据此擅写剧情永久封技、城市毁灭、角色死亡或推进数天冷却。
- 艾利丝同名能力仍保留独立角色来源；复用效果组件可以，但是否采用同一游戏技能配置后续明确，不因名称相同混用。

## 辅助角色：允许设计，不强加攻击能力

用户已允许明空这类未写战斗技能的角色作为辅助，提供buff（增益效果）、治疗等。明空列为已授权辅助设计；根据目前资料，叶、瓦尔基里、阿兰雅也可按此路线制作辅助候选，不再因没有能力栏停工。具体首玩阵容/获取与解锁仍未因此确定。

| 角色 | 可先制作的辅助设计候选 | 表现注意 |
|---|---|---|
| 明空 | 基础鼓励/援护、定向治疗、短期保护增益、团队恢复型大招 | 轻动作与同伴互动、补给/药物/游戏化援护表现；不自动赋予世界书未记载的强攻超能力 |
| 叶 | 实验补给、治疗/净化候选、队友增益、强化团队的大招 | 实验器具与补给动作有依据；具体药品/装置是游戏设计候选，不反写成原作既定能力 |
| 瓦尔基里 | 指挥增益、队伍保护、行动协同、团队强化大招 | 仪态与指挥动作清楚，不从骑士制服直接推导固定近战武器 |
| 阿兰雅 | 援护/补给、团队恢复、持续支持、群体援助大招 | 保留精灵角色身份，不把物种自动当作弓箭/某系魔法证明 |

辅助也沿用八个动作槽和待机，但attack槽在显示与规则上可解释为**基础援护**：例如为队友施加小幅增益或轻量恢复。保留稳定action_id便于框架统一，玩家看到的名称与合法目标按辅助行为呈现，不把“普攻”硬做成伤害技能。skill_1/skill_2/ultimate可以都是支持行动。

制作时必须补合法队友目标、满血/无可用对象、效果重复/覆盖、增益显示/到期、连续治疗、辅助本人受击/防御/倒地与结算的反馈；不能只画施法动画而不测被援护者的状态和反馈。增益叠加/治疗量/目标范围/净化存在与否按实际规则确定，不能把本段举例全部当必做系统。

当前七罪119条主动作统计保持独立。辅助角色进入明确制作批次时，每人按单形态8条主动作＋1条待机登记；未定首玩名单不混进119条完成比例，当前也不虚报已制作。
