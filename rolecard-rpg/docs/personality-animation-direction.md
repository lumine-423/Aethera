# 人设如何进入动作与验收

更新2026-10-28。用户明确要求各种动画体现角色人设；该项与自然动力学、统一像素风格同时是验收条件。性格原文从已核验世界书相关角色段读取，动作解释是制作候选，不伪称世界书逐字规定了某个姿势。

详细来源与逐角色方向在`art-source/personality-profiles.json`；通过`python tools/art_pipeline.py profile --actor <id>`只读一个角色。17名来源角色均有档案；焰渊保留两个剧情阶段来源，不将其误作七罪解放。

“稳健、帅气、优雅、冒失”不是四个批量模板。只有来源支持时才采用，尤其不能为做出差异就让技艺高强角色失去基本功。冒失可以是少量表情/收势的小插曲，若适合也不能让人物长期站不稳、攻击乱挥或破坏操作反馈。

## 每个动作卡都要回答

1. **待机**：重心高低、呼吸幅度、视线方向、手部/武器习惯、头发/衣物的延迟；这套循环为什么像此人？
2. **普攻/基础援护**：预备是否急促/从容、力量从哪里传出、关键手势、收招节奏；辅助者不被硬套伤害姿势。
3. **技能1/2**：每个槽分别写动作路径、目标关注和个性手势。两条技能不能只换特效颜色，也不能只把角色性格词复制两遍。
4. **大招**：力量顶峰时角色如何保持自身气质？视线、身体开放程度、停顿和收束如何不同？不可让所有人同一张霸气笑脸。
5. **受击**：第一反应、承力、保护要害、恢复戒备；克制不等于没有痛感，体弱不等于夸张羞辱。
6. **防御**：为什么保护、身体怎样支撑、何时退出；人设差异不改变规则已承诺的反馈。
7. **倒地**：失衡到落地的物理过程、最终稳定姿势；不因人设强大就省掉失能动作。
8. **结算**：先关注自己还是同伴？是克制致意、轻快得意、从容收势还是温柔松一口气？按胜负/存活状态选择，不让倒地者无故欢呼。
9. **解放与第二套**：形态放大既有人设，不另造一个陌生人格；持物、重心与附属物改变要有动作原因。

验收时隐藏角色名和技能特效，先看剪影/站姿/节奏，记录能否读出预定气质以及最像通用模板的段落。这是辅助检查，不以“猜中角色”当唯一标准；最终仍逐项检查源设定、动作卡和完整上下文。人设符合、自然动力学、资源结构三个维度分别判定，任何失败都不得被平均分抵消。
